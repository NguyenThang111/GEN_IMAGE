# JSON đã sửa lỗi component

- SH Mode: 7 mạch lỗi component đã sửa; Vario: 9 mạch. Cung cấp đủ 12 mạch mỗi xe để nạp lại.
- Mở review.html xem ảnh gốc và PNG dựng bằng renderer của web.
- JSON trong folder xe đã dùng vehicleId, id, vehicleTitle, circuitTitle đúng các project trong ảnh chụp.
- Nạp từng circuit bằng ảnh GỐC trong source và JSON cùng số. Smartkey/PGM-FI có sourceTransform, không chọn preview xoay làm ảnh nguồn.
- Không còn loại component ngoài danh sách Studio gốc. symbolType giữ nghĩa ký hiệu cũ; drawing giữ hình chi tiết.
- Không thay đổi chân, mạng điện hoặc mã màu để xóa cảnh báo. NEEDS_REVIEW còn các đường chéo/trace clearance theo ảnh và nội dung điện chưa được phê duyệt.
- Chưa cập nhật cơ sở dữ liệu trên website.
- AIR BLADE 160 2026: đã có ảnh gốc nhưng chưa tìm thấy JSON đang lỗi hoặc ZIP project. Hai ảnh PGM-FI trong nguồn có sơ đồ chân khác nhau; cần xác định JSON của project trước khi sửa, không dùng bộ AirBlade 2011–2012 thay thế.
